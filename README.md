# EthioUniversity Guide

A modern web platform for discovering and comparing Ethiopian universities.

## Features

- Browse detailed profiles of Ethiopian universities
- Compare universities side by side
- Search and filter by type and location
- View programs, facilities, and contact information

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

```bash
npm install
npm run dev
```
